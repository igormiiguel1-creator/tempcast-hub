# Preferências

## Comunicação

- Responder ao utilizador em português.
- Textos visíveis na aplicação: português de Portugal.
- Explicar as escolhas técnicas feitas, para que o utilizador as possa redirecionar.

## Trabalho

- Fazer alterações pequenas e verificáveis.
- Confirmar o problema operacional antes de propor uma funcionalidade nova.
- Quando houver uma parte bloqueada, avançar com o resto e dizer claramente o que ficou por fazer.
