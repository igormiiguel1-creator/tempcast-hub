# 1. Visão do Produto

O TempCast Hub é uma plataforma premium para gestão completa de podcasts e criadores de conteúdo.

O objetivo não é apenas organizar episódios.

Pretende-se criar um verdadeiro Centro de Operações para produtores de conteúdo, permitindo controlar todo o ciclo de produção desde a ideia inicial até à publicação e análise de resultados.

A aplicação deverá transmitir uma sensação semelhante a produtos como:

- Linear
- Notion
- Arc Browser
- Apple
- Raycast

A prioridade será sempre:

- simplicidade
- rapidez
- organização
- inteligência
- automatização

---

# 2. Objetivos

O TempCast Hub deverá permitir:

- Centralizar toda a produção do TempCast.
- Eliminar folhas Excel.
- Reduzir tarefas repetitivas.
- Automatizar processos.
- Acompanhar métricas.
- Controlar custos.
- Gerir convidados.
- Melhorar a produtividade.
- Apoiar decisões através de IA.

No futuro deverá tornar-se um produto comercial.

# 5. Filosofia

A aplicação nunca deverá parecer um software de gestão tradicional.

Queremos transmitir uma experiência premium.

Cada ecrã deve responder imediatamente às seguintes perguntas:

• O que tenho para fazer?

• O que está atrasado?

• O que é importante hoje?

• Qual o próximo passo?

Nunca deverá existir excesso de informação.

Cada clique deverá aproximar o utilizador do objetivo.

---

# 6. Design

O design será baseado em:

- muito espaço em branco
- poucos elementos
- hierarquia clara
- tipografia forte
- animações discretas
- cartões modernos
- ícones simples
- sombras suaves
- micro-interações

As cores da marca TempCast serão utilizadas apenas como destaque.

Nunca deverão dominar a interface.

---

# 7. Inteligência Artificial

A IA será um dos pilares da aplicação.

O objetivo não é apenas responder a perguntas.

A IA deverá ajudar diariamente.

Exemplos:

- sugerir convidados
- gerar títulos
- gerar descrições
- criar posts
- analisar métricas
- identificar tendências
- criar checklists
- sugerir próximos passos

No futuro poderá funcionar como um verdadeiro COO do TempCast.

# 10. Objetivo Comercial

O TempCast Hub deverá ser desenvolvido desde o primeiro dia como um produto SaaS.

Mesmo que inicialmente seja utilizado apenas pelo TempCast.

No futuro deverá permitir:

- múltiplos utilizadores
- múltiplos podcasts
- equipas
- permissões
- planos pagos
- faturação
- subscrições

---

# 11. Regras do Projeto

Nunca desenvolver funcionalidades sem especificação.

Nunca criar código duplicado.

Priorizar sempre:

- simplicidade
- manutenção
- escalabilidade
- performance

Todas as decisões deverão permitir crescimento futuro.
